# Archive Inputs

This directory stores finalized weekly input payloads that are worth keeping as reproducible fixtures.

Keep here:
- normalized `*.cards.json` inputs that were actually used to render a published week
- optional `*.source-data.json` snapshots that explain where the normalized payload came from

Do not keep here:
- temporary experiments
- duplicated PNG or SVG output files
- ad hoc scratch notes from the vault

Recommended naming:
- `YYYY-MM-DD_to_YYYY-MM-DD.cards.json`
- `YYYY-MM-DD_to_YYYY-MM-DD.source-data.json`
